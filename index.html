Challenge

Nine related tables with traps: one customer ID per order, reviews shared by several orders, 1 million rows of geolocation for 19,000 postcodes.

Approach

Declared the grain of every table first, then built a star schema with 2 fact tables and 4 dimensions, aggregating before joining so totals never inflate.

Engineering

Keyless access with a managed identity, incremental merge for late data, serverless compute, Terraform for every resource, CI on each push.
Key decisions (architecture decision records)
  1. Infrastructure as code with Terraform: the whole platform is created and deleted with one command, which keeps the cloud cost at zero when it is not in use.
  2. Keyless access from Databricks to the data lake with a managed identity and least-privilege roles.
  3. dbt for the silver and gold layers, with tests on every run.
  4. Replay of the history as a live store, loaded incrementally.
  5. Serverless compute for the daily job and the SQL warehouse, to pay only while it runs.

04.Code samples

Short excerpts from the repositories: the patterns that do the heavy lifting.

Fuel Price History. Gaps and islands: lag() flags a price change, a running sum() numbers each price spell, lead() closes it. View repository

-- SCD type 2: one row per station and price spell
WITH flagged AS (
    SELECT
        station_id, price_date, price_gasoline_95, price_diesel,
        CASE
            WHEN lag(price_date) OVER w IS NULL THEN 1
            WHEN price_gasoline_95 IS DISTINCT FROM lag(price_gasoline_95) OVER w
              OR price_diesel      IS DISTINCT FROM lag(price_diesel) OVER w THEN 1
            ELSE 0
        END AS is_new_spell
    FROM {{ ref('prices_daily') }}
    WINDOW w AS (PARTITION BY station_id ORDER BY price_date)
),

spells AS (
    SELECT *, sum(is_new_spell) OVER (PARTITION BY station_id ORDER BY price_date) AS spell_number
    FROM flagged
),

collapsed AS (
    SELECT station_id, spell_number,
           min(price_date) AS valid_from,
           any_value(price_gasoline_95) AS price_gasoline_95,
           any_value(price_diesel) AS price_diesel
    FROM spells
    GROUP BY station_id, spell_number
)

SELECT
    station_id, price_gasoline_95, price_diesel, valid_from,
    lead(valid_from) OVER (PARTITION BY station_id ORDER BY valid_from) - INTERVAL 1 DAY AS valid_to,
    lead(valid_from) OVER (PARTITION BY station_id ORDER BY valid_from) IS NULL AS is_current
FROM collapsed

E-commerce Data Pipeline. Only orders that changed since the last run are merged, including late deliveries and reviews. Reviews are aggregated before the join so rows never multiply. View repository

{{ config(materialized='incremental', unique_key='order_id', incremental_strategy='merge') }}

-- Several reviews per order: aggregate to one row per order BEFORE joining
WITH reviews AS (
    SELECT order_id,
           avg(review_score) AS review_score,
           max(created_at)   AS last_review_at
    FROM {{ ref('order_reviews') }}
    GROUP BY order_id
),

orders AS (
    SELECT
        o.order_id,
        CAST(o.purchased_at AS DATE) AS purchase_date,
        o.delivered_to_customer_at > o.estimated_delivery_at AS is_late,
        r.review_score,
        greatest(o.updated_at, r.last_review_at) AS updated_at
    FROM {{ ref('orders') }} AS o
    LEFT JOIN reviews AS r ON o.order_id = r.order_id
)

Wiki Stream Pulse. At-least-once delivery can repeat events after a restart. QUALIFY keeps the first copy of each event; windows use event time, not arrival time. View repository

-- Silver: one row per event, even if a batch was delivered twice
SELECT *, epoch(received_at) - epoch(event_time) AS lag_seconds
FROM typed
QUALIFY row_number() OVER (PARTITION BY event_id ORDER BY received_at) = 1;

-- Gold: per-minute windows on EVENT time (when the edit happened)
CREATE OR REPLACE TABLE gold.edits_per_minute AS
SELECT
    date_trunc('minute', event_time)       AS minute,
    count(*)                               AS events,
    count(*) FILTER (WHERE type = 'edit')  AS edits,
    count(*) FILTER (WHERE type = 'new')   AS new_pages,
    count(*) FILTER (WHERE is_bot)         AS by_bots
FROM silver.events
GROUP BY ALL;
